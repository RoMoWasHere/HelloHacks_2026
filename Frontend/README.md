# Chrome Extension Starter

This folder contains Google's official **Getting Started** Chrome extension sample from [GoogleChrome/chrome-extensions-samples](https://github.com/GoogleChrome/chrome-extensions-samples/tree/main/functional-samples/tutorial.getting-started).

## Load it in Chrome

1. Open `chrome://extensions`.
2. Turn on **Developer mode**.
3. Select **Load unpacked** and choose this `Frontend` folder.
4. Open a web page, then use the extension popup to change its background color. Set the color from the extension's Options page.

The sample demonstrates a Manifest V3 service worker, popup, options page, and Chrome storage, tabs, and scripting APIs. Google’s [debugging tutorial](https://developer.chrome.com/docs/extensions/get-started/tutorial/debug) explains the example. See `LICENSE` for the upstream license.
